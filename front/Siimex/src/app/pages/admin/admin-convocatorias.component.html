Reglas personalizadas de convocatoria

Agrega reglas libres para esta convocatoria (clave/valor). Puedes editarlas, eliminarlas y crear las que necesiten. Para control operativo usa, por ejemplo: postulacion_fecha_inicio, postulacion_fecha_fin, postulacion_estados_editables, plazo_correccion_horas_default e informes_requeridos (NINGUNO, PARCIAL, FINAL, AMBOS).

Criterios del formulario de postulación

Define los campos que verán los usuarios al postularse. El peso (1-100) se usa para calcular el % de compatibilidad. Usa claves como grado_academico, tipo_perfil, anios_experiencia, area_conocimiento, idiomas para que coincidan con el perfil del usuario.

Requisitos de documentos

Define qué documentos deben adjuntar los postulantes. Cada apartado será un campo de carga de archivo (solo PDF).
